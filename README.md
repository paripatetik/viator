# Viator — Philosophy Blog

Headless blog frontend built with Next.js, using WordPress as a backend via REST API, focused on clean typography and structured long-form content.

## Tech Stack
- Next.js
- Tailwind CSS
- WordPress REST API
- JavaScript (ES6+)

## Features
- Dynamic article pages with API-based content
- Headless CMS architecture (WordPress + Next.js)
- Structured layout for long-form reading
- Responsive design across devices
- Clean, minimal UI focused on readability
